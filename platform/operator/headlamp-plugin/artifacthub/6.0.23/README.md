# di-framework Platform Instances 6.0.23

A [Headlamp](https://headlamp.dev) plugin for di-framework PlatformInstances
(`platform.di-framework.dev/v1alpha1`), released with di-framework platform v6.0.23.

The platform operator's Helm chart installs it through Headlamp's plugin manager. See the
[plugin README](https://github.com/di-framework/platform/blob/v6.0.23/platform/operator/headlamp-plugin/README.md).
