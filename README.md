# di-framework/platform

Operated wasmCloud platform for di-framework.

| Path | Package |
| --- | --- |
| `platform/platform` | `@di-framework/platform` (cluster install: Pulumi, CRDs, controller, tenancy) |
| `platform/bindings` | `@di-framework/bindings` (app guests) |
| `platform/sqlite-component` | `@di-framework/sqlite-component` |
| `platform/backup-agent` | `@di-framework/backup-agent` (stub until the backup operator ships) |
| `platform/backup-destination` | `@di-framework/backup-destination` (stub) |
| `adapters/cloudfoundry` | `@di-framework/cloudfoundry` |

User-facing CLI commands live in `di-framework/cli-extensions` (`@di-framework/cli-plugin-platform`).

First publish from this remote is **6.0.0**.
