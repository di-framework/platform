# @di-framework/platform

Operated wasmCloud platform for di-framework: the cluster package (`@di-framework/platform`), app guests (`@di-framework/bindings`), SQLite component, backup image/chart, and foreign adapters such as Cloud Foundry VCAP. User-facing CLI commands live in `di-framework/cli-extensions`.

This tree is a bun workspace stub for the v6 split ([#485](https://github.com/di-framework/di-framework/issues/485)). Package source moves here in follow-up extract issues.
